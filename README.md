# 🎧 InfiniteAudioArchive — Cloud Waveform Library

A premium, cloud‑powered audio archive built with **Supabase**, **Vercel**, and a **brutal gradient waveform visualizer**.  
Upload, search, organize playlists, and render reactive waveforms — all in the browser.

---

## 🚀 Features

- **Cloud storage (Supabase Storage)**
- **Upload audio files**
- **Delete audio files**
- **Search bar with instant filtering**
- **Local + cloud‑ready playlists**
- **Gradient waveform visualizer**
- **Brutal++ distortion mode**
- **Responsive premium UI**
- **Vercel deployment ready**
